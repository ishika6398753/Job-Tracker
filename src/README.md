# Job Tracker

A React-based web application to manage and track job applications.

## About the Project

Job Tracker helps users keep track of their job applications
in one place. Users can add, update, delete and manage
their job application details.

## Features

- Login and Signup
- Add New Job
- Edit Job Details
- Delete Job
- Search Jobs
- Filter Jobs by Status
- Sort Applications
- Dashboard Statistics
- Application Progress Bar
- LocalStorage Data Saving
- Dark Mode
- Profile Page
- CSV Export
- Interview Reminder

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the command:

   npm install

4. Then run:

   npm run dev

5. Open the local URL shown in the terminal.

## Project Objective

The objective of this project is to practice React
and develop a useful job application management system.
